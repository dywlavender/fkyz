## 页面 1：单因子评审（默认页）

### 输入区域（从上到下排列）

| 区域 | 阶段标识 | 必填 | 说明 |
|------|---------|------|------|
| **因子基础信息** | Phase 1 | 是 | 输入因子中文名 |
| **需求内容** | Phase 1 | 是 | 业务背景、使用场景及加工逻辑描述 |
| **关联接口文档** | Phase 1 | 是 | 从接口文档库中选择关联的接口文档（点击芯片切换选中） |
| **待评审准出内容** | Phase 2 | 是（Phase 2 时） | 包含因子加工输入字段、加工逻辑、默认值三个子字段 |

#### 待评审准出内容 — 子字段

| 字段 | 必填 | 格式 |
|------|------|------|
| 因子加工输入字段 | 否 | 每行一个字段，推荐格式：`字段名 \| 字段来源 \| 用途` |
| 加工逻辑 | 是 | 逐步描述加工逻辑 |
| 默认值 | 否 | 无数据时的兜底返回值 |

### 操作按钮

#### ⚡ 一键评审（Phase 1 + Phase 2）
- **位置**：待评审准出内容下方，分阶段栏上方
- **效果**：紫色渐变按钮，全宽度
- **功能**：自动串联执行两个阶段。先验证全部输入（含待评审内容），再依次执行 Phase 1 → Phase 2
- **适用场景**：从头到尾完整评审，一次性完成

#### ■ 停止评审
- **位置**：一键评审按钮右侧，仅任务运行中显示
- **功能**：向后端发送取消请求，停止当前 Phase 1 或 Phase 2 任务
- **状态**：点击后进入「停止中...」，后端确认取消后恢复可操作状态

### 分阶段评审与调试

Phase 1、Phase 2 单独执行入口默认收起在「分阶段评审与调试」折叠区中，主路径优先使用「一键评审」。

展开后可执行以下高级操作：

#### Phase 1 · 生成标准规范
- **按钮**：`▷ 生成标准规范`
- **功能**：仅发送因子名 + 需求内容 + 接口文档到后端，不接触待评审内容
- **输出**：左侧 Phase 1 面板展示完整的标准加工规范（含因子加工输入字段、字段溯源、过滤条件、计算逻辑、默认值兜底策略等）
- **状态**：按钮下方有行状态指示（等待 → 生成中 → 完成 ✓）

#### Phase 2 · 生成评审报告
- **按钮**：`▷ 生成评审报告`
- **条件**：需要 Phase 1 先完成（完成后自动解锁）
- **功能**：读取 Phase 1 生成的标准规范 + 待评审准出内容，进行对比评审
- **输出**：左侧 Phase 2 面板默认展示「总体结论」和「汇总问题清单」，可点击「完整报告」查看完整报告
- **状态**：同 Phase 1 有行状态指示

#### ⟳ 重新生成评审报告（已隐藏）
> 此按钮已隐藏。Phase 2 完成后，直接再次点击主按钮 `▷ 生成评审报告` 即可用新输入重新生成。

#### Claude 调试输出
- **开关**：`显示 Claude 调试输出`
- **入口**：`查看调试日志`
- **说明**：调试输出仅本次运行临时展示，不写入文件
- **滚动行为**：打开弹窗时默认定位到最新日志；任务刷新时，只有当前滚动位置接近底部才自动跟随到底部。若用户手动上滑查看中间内容，后续刷新不会强制跳到底部。

### 三栏结果布局

Phase 1 和 Phase 2 生成后，结果区域以三栏展示：

```
┌───── Phase 1 面板 ─────┬───── Phase 2 面板 ─────┬── 评审概览 ──┐
│ 标准加工规范            │ 评审报告                │ 总体结论     │
│                         │                        │              │
│ [完整内容] [复制规范]    │ [完整报告] [复制报告]   │ 不符合: N    │
│                         │                        │ 待确认: N    │
│ Phase 1 全部内容        │ 默认：总体结论+问题清单 │ 建议: N      │
│ 默认全量展示，无数据丢失  │ 点击展开完整报告        │              │
│                         │                        │ 运行日志      │
│ 状态: 已生成 ✓          │ 状态: 已生成 ✓          │              │
└─────────────────────────┴────────────────────────┴──────────────┘
```

| 区域 | 说明 |
|------|------|
| **Phase 1 面板** | 默认全量展示标准加工规范，无数据丢失 |
| **Phase 2 面板** | 默认展示「总体结论 + 汇总问题清单」，点击「完整报告」查看精简报告全文 |
| **评审概览** | 总体结论 banner + 三级统计（不符合/待确认/建议） |
| **运行日志** | 实时显示后端任务执行状态 |

## 页面 2：批量评审

### 功能

支持通过 CSV 或 Excel 文件批量导入多条因子进行评审。

### 操作流程

1. **导入文件**：点击「选择文件」或拖拽 CSV/Excel 到上传区域
2. **下载模板**：点击「下载模板」可获取 CSV 模板
3. **预览数据**：文件解析后展示数据预览表格
4. **开始评审**：点击「▷ 开始批量评审」，按设置的并发数提交评审任务
5. **进度查看**：实时显示每条任务的完成状态（等待/运行中/完成/失败/跳过）
6. **结论查看**：每条记录右侧展示最终「总体结论」（通过/待确认/不通过/异常/跳过）
7. **查看详情**：点击单条结果的「详情」按钮，在历史详情弹窗中查看标准规范、评审报告和概览

### 文件格式要求

| 列名 | 必填 | 说明 |
|------|------|------|
| 因子名 | 否 | 因子中文名称 |
| 需求内容 | 是 | 业务描述 |
| 接口文档 | 否 | 接口名，多个用顿号/逗号分隔 |
| 因子加工输入字段 | 否 | 字段列表，可直接写字段名，也可写 `字段名 | 字段来源 | 用途` |
| 加工逻辑 | 否 | 逐步描述 |
| 默认值 | 否 | 兜底返回值 |

## 页面 3：验证集工作台

### 功能

维护和运行验证用例，支持单条验证、记录当前结果和一键回归验证。

### 工作区组成

| 区域 | 说明 |
|------|------|
| **验证统计** | 展示用例总数、最近通过、最近未通过、未验证 |
| **搜索和筛选** | 可按标题、因子、需求、接口、类型、状态过滤用例 |
| **最近验证结果** | 展示当前用例最近一次结论、期望匹配和问题数 |
| **验证用例列表** | 左侧列表展示用例标题、因子名和最近状态 |
| **用例编辑** | 右侧表单维护标题、类型、因子、接口、需求、因子加工输入字段、加工逻辑、默认值、期望结论 |

### 操作

- **验证当前用例**：将当前选中的用例加载到单因子评审页，并执行一键评审
- **一键回归验证**：后端批量执行全部验证用例，前端实时更新进度
- **停止回归**：运行中可停止后续回归任务
- **记录当前结果**：将单因子页当前 Phase 2 报告记录为所选用例最近结果
- **加载到评审页**：只填充单因子评审表单，不立即运行

### 渲染约定

回归轮询期间，前端只在验证结果发生变化时刷新统计、列表和结果面板；筛选项和列表点击使用轻量事件委托，避免高频全量重渲染影响操作。

## 页面 4：评审历史

### 功能

查看所有已完成的评审记录，支持勾选删除。

### 操作

- **查看详情**：点击任意记录行（非 checkbox 区域）弹出历史详情弹窗
- **勾选删除**：
  1. 每条记录左侧始终显示 checkbox
  2. 勾选后顶部出现「✕ 删除选中 (N)」按钮
  3. 点击删除，确认后从本地存储中移除
  4. 取消勾选则删除按钮自动隐藏

### 历史详情弹窗

历史详情弹窗支持三种视图：

| 视图 | 说明 |
|------|------|
| **只看问题** | 默认视图，聚焦总体结论和问题清单，隐藏 Phase 1 标准规范 |
| **标准/报告** | 对比查看 Phase 1 标准加工规范、Phase 2 评审报告和评审概览 |
| **输入信息** | 单独查看该次评审的需求、因子加工输入字段、逻辑、默认值、接口等输入摘要 |

## 页面 5：接口文档库

### 功能

浏览和管理本地 `raw/api/` 目录下的接口文档。

### 布局

```
┌── 左侧文档树 ──┬── 右侧文档预览 ─────────────┐
│ [搜索接口名...] │ 文档名称 / 方法 / 版本 / 状态 │
│                 │                              │
│ ▼ 本系统接口    │ 可用字段表                    │
│   ├ 授信申请    │ 字段路径与说明                │
│   ├ 提款申请    │                              │
│   └ Test1申请   │                              │
│ ▼ 外部接口      │                              │
│   ├ EDAP_企业.. │                              │
│   └ ES_医药..   │                              │
└─────────────────┴──────────────────────────────┘
```

- **搜索**：实时过滤，匹配接口名和文档内容
- **分类**：按 `raw/api/` 下的目录分为「本系统接口」「外部接口」「其他」，可折叠
- **文档预览**：点击文档树中的条目，右侧展示字段表等结构化内容

## 数据流说明

```
用户输入 → 前端验证 → 后端 API → Claude Code → 结果返回 → 前端渲染
```

### Phase 1 流程

```
前端 POST /api/review/phase1
  body: { factorName, requirement, apiNames }
  ↓
后端读取 risk-review-skill/phase/phase1_standard.md + 接口文档 → 构建 Phase 1 Prompt → 调用 claude -p
  ↓
Claude 输出标准加工规范 → 后端写入 outputs/standard-<slug>.md → 返回 standardFileId + checksum
  ↓
前端渲染 Phase 1 面板
```

### Phase 2 流程

```
前端 POST /api/review/phase2
  body: { factorName, draft, standardFileId }
  ↓
后端读取 standard-<slug>.md + 结合 draft → 构建 Phase 2 Prompt → 调用 claude -p
  ↓
Claude 输出评审报告 → 后端返回结果
  ↓
前端渲染 Phase 2 面板（默认：总体结论 + 汇总问题清单）
```

### 一键评审流程

```
前端 runFullReview()
  → 先调 runPhase1() 
  → Phase 1 完成后自动调 runPhase2()
  → 用户无需分步操作
```

## 前端交互维护约定

- 单因子评审以「一键评审」为默认主路径，分阶段执行和 Claude 调试属于高级操作，默认收起。
- 高频轮询场景避免整块 DOM 反复 `innerHTML` 重建；优先使用签名判断、局部刷新和事件委托。
- 调试日志、运行日志等长文本区域，自动滚动必须尊重用户当前位置：只有接近底部时才自动跟随最新内容。
- 历史详情、批量详情、验证结果详情复用同一套详情弹窗语义，默认先展示问题摘要，再允许查看完整标准和报告。
- 运行产物统一保存到项目根目录 `outputs/`，不要写入 `wiki/outputs/`。

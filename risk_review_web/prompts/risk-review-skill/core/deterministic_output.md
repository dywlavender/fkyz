# Deterministic Output v4

相同输入必须输出相同章节、相同规则顺序和同一套最可能加工逻辑。

## Phase 1 章节顺序

1. `# 标准加工规范`
2. `## 输入解析`
3. `## 因子加工输入字段`
4. `## 字段溯源`
5. `## 过滤条件`
6. `## 列表/数组字段处理`
7. `## 计算逻辑`
8. `## 默认值兜底策略`
9. `## 比率/衍生因子计算`
10. `## 条件分支逻辑`
11. `## 选定解释`

## Phase 2 章节顺序

1. `# 评审报告`
2. `## 输入解析`
3. `## 总体结论`
4. `## 汇总问题清单`
5. `## 待确认项`

规则编号固定使用 D1-D6、D8-D9；D6 之后直接使用 D8、D9。选定解释使用 SEL-001 起连续编号。

不得输出主链“未明确”“待确认”“建议口径”或多套候选方案。必须选择一个最可能且可执行的标准答案。
